行内样式：直接在便签上加 style 属性

内部样式：在 HTML 文档的 head 标签内部使用 style 标签来定义 CSS 样式

外部样式：将 CSS 样式定义在一个外部的 CSS 文件中，然后在 HTML 文档中引入该文件

css常用的属性：
1. color：设置文本颜色
2. font-size：设置字体大小
3. background-color：设置背景颜色
4. text-align：设置文本对齐方式
5. margin：设置元素的外边距
6. padding：设置元素的内边距
7. border：设置元素的边框
8. width：设置元素的宽度
9. height：设置元素的高度
10. display：设置元素的显示方式
css设置元素的属性：
1. color：设置文本颜色
2. font-size：设置字体大小
3. background-color：设置背景颜色
4. text-align：设置文本对齐方式
5. margin：设置元素的外边距
6. padding：设置元素的内边距
7. border：设置元素的边框
8. width：设置元素的宽度
9. height：设置元素的高度
10. display：设置元素的显示方式
csss设置文本的常用属性：
1. text-decoration-color：设置文本装饰线的颜色
2. text-decoration-line：设置文本装饰线的类型
3. text-decoration-thickness：设置文本装饰线的粗细
css布局属性
1. float：设置元素的浮动方式
2. clear：清除元素的浮动
3. position：设置元素的定位方式
4. top、right、bottom、left：设置元素的定位偏移量
5. z-index：设置元素的堆叠顺序
6. overflow：设置元素的内容溢出处理方式
7. display：设置元素的显示方式
8. visibility：设置元素的可见性
9. width：设置元素的宽度
10. height：设置元素的高度
css设置背景属性：
1. background-color：设置背景颜色
2. background-image：设置背景图片
3. background-repeat：设置背景图片的重复方式
4. background-position：设置背景图片的位置
5. background-size：设置背景图片的大小
6. background-attachment：设置背景图片的固定方式
css设置边框属性：
1. border-width：设置边框宽度
2. border-style：设置边框样式
3. border-color：设置边框颜色
4. border-radius：设置边框圆角
5. border：设置元素的边框
6. border-top、border-right、border-bottom、border-left：设置元素的边框方向
7. border-top-width、border-right-width、border-bottom-width、border-left-width：设置元素的边框方向宽度
8. border-top-color、border-right-color、border-bottom-color、border-left-color：设置元素的边框方向颜色
9. border-top-style、border-right-style、border-bottom-style、border-left-style：设置元素的边框方向样式
10. border-top-left-radius、border-top-right-radius、border-bottom-right-radius、border-bottom-left-radius：设置元素的边框方向圆角
